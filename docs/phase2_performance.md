# Phase 2 measured simulation performance

Generated by `python3 tests/run_phase2.py --report docs/phase2_performance.md`.

Both cores use a 10 ns simulation clock. Execution time is counted active cycles multiplied by 10 ns, through the final useful instruction's WB edge (the completion edge for Phase 1). Reset cycles and the 1 ns state-observation delay are excluded. This is whole-cycle accounting, not final timestamp minus reset-release timestamp.

Single-cycle programs contain no scheduling NOPs. Pipeline programs explicitly space dependencies. Useful instructions exclude NOPs and include executed branches/stores. Cycles include pipeline fill/drain, scheduling NOPs, and taken-branch flushes.

Speedup = single time / pipeline time. A value below 1 means the pipeline is slower at the equal test clock. To beat the baseline, pipeline frequency must exceed single-cycle frequency multiplied by the last column. These are simulated cycle/time measurements, not measured maximum hardware frequencies. All rows passed checks of all 32 register slots, all 64 data-memory words, exact retirement PC sequence, and expected cycle count. Test fixtures initialize registers/RAM to zero; hardware reset does not clear those arrays.
